# Synthetic init package

`smoke_pair.db` is a two-camera, 40-second synthetic overlap scene. It is
generated by `scripts/init_smoke_data.py` and contains no licensed dataset
content.

- Scene id: `smoke_pair`
- Batch id: `smoke_001`
- Cameras: `CA` (higher kappa), `CB` (lower kappa)
- Split: 60/10/30 contiguous time, see `splits/smoke_split_manifest.csv`
- Geometry version: `fab1_metric_jacobian_v1`

Regenerate at any time; the file is deterministic given the script.
